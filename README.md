# Ur5e_deepRL
This repository contains the code, datasets, and experimental design for the Advanced Topics in Advanced Control project.
The research addresses the challenge of high-dimensionality in trajectory optimization using Deep Reinforcement Learning applied to UR5e robotic manipulators. 

## Methodology
The methodology for this research is based on the integration of Deep Reinforcement Learning (DRL) to address the challenge of high-dimensionality in trajectory optimization for UR5e robotic manipulators. The research leverages MuJoCo (Multi-Joint dynamics with Contact), a physics engine, to simulate the UR5e manipulator's interactions with its environment.
